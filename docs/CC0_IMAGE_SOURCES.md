# Public-domain coloring asset sourcing (October 2026)

This site hosts a curated set of 10 vector illustrations from [Openclipart](https://openclipart.org/faq), mirrored in the [openclipart-svg archive](https://github.com/cyanidecupcake/openclipart-svg).

The source archive includes the [CC0 1.0 Universal dedication](https://github.com/cyanidecupcake/openclipart-svg/blob/master/LICENSE), which allows redistribution and commercial reuse, with no attribution requirement. We nevertheless retain an original source link on each coloring page.

**Import procedure:** SVGs are copied into `public/coloring/cc0/`, and sanitized to strip active script, foreign resources and metadata. Images are served locally rather than hotlinked. Metadata, category and source URL are stored in `src/lib/data/curatedColoring.ts`.

**Editorial safeguards:** Independently assess each upload for third-party trademarks, copyrighted characters, image accuracy, and fitness as line art. Avoid content that appears to copy contemporary commercial media. A CC0 declaration does not guarantee that all third-party rights are resolved.

This is a curated collection, not a claim of original authorship by CraftColoring.
